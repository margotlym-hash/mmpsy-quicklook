# L0/L1 · 最简基线：TF-IDF + 逻辑回归

- N=1275，有症状 839 人（66%），Normal 436 人
- 模型：词频向量（1-2元词组）+ 逻辑回归——没有任何神经网络

## 5 折交叉验证结果

```
              precision    recall  f1-score   support

      Normal      0.456     0.475     0.465       436
         有症状      0.721     0.706     0.713       839

    accuracy                          0.627      1275
   macro avg      0.589     0.590     0.589      1275
weighted avg      0.630     0.627     0.628      1275

```
- Accuracy：0.627
- **AUC：0.634**　← 和论文 BERT 多任务系统的抑郁 AUC 0.877 放在一起看

```
基线参照：全部猜'有症状'的准确率 = 66%
```

这两个数之间的差，就是深度模型在这个任务上的真实增量。
（注意：论文测的是量表分数回归+三分类，这里是二分类，数字不能直接对齐，
方向性对比即可；下一步 L2 换 BERT 时用同一套 5 折划分才能严格对比。）
